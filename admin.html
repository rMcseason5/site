Guardar alterações

Este painel edita os dados diretamente no teu navegador. Para que as alterações apareçam para todas as pessoas que visitam o site, tens de:

  1. Clicar em "Descarregar data.json" abaixo.
  2. Substituir o ficheiro data.json na raiz do teu repositório GitHub pelo ficheiro descarregado.
  3. Fazer commit & push. O site atualiza-se automaticamente (GitHub Pages).
